# pertemuan-01
1. Kesinambungan PWD–DPW–DPWL
= PWD menjadi dasar pemahaman web dinamis,dan DPW menerapkannya dalam pembuatan aplikasi web, sedangkan DPWL mengembangkan aplikasi dengan konsep yang terstruktur, seperti MVC.

2. Perbedaan PHP Terstruktur dan MVC
 = PHP terstruktur: kode program diketik secara rinci tetapi proses, data, dan tampilan masih dapat berada dalam satu bagian.
-MVC: aplikasi dipisahkan menjadi Model, View, dan Controller sehingga lebih mudah digunakan.

3. Fungsi Model, View, dan Controller
= -Model: Mengelola data dan database.
-View: Menampilkan antarmuka kepada pengguna.
-Controller: Mengatur proses dan menghubungkan Model dengan View.

4. Alur Request–Response MVC
= User → Request → Controller → Model → Database → Controller → View → Response → User.
-Controller menerima permintaan,
-Model mengolah data jika diperlukan, 
-View menampilkan hasil kepada pengguna.

5. Pemetaan Fitur Aplikasi DPW
= Contoh fitur data mahasiswa:
-Model: Mengelola data mahasiswa di database.
-Controller: Menangani proses tambah, edit, hapus, dan tampil data.
-View: Menampilkan tabel dan form mahasiswa.

6. Kesimpulan P1
= PWD, DPW, dan DPWL saling berkesinambungan dalam pengembangan web. MVC membuat aplikasi lebih terstruktur karena data, proses, dan tampilan dipisahkan. Dengan begitu, aplikasi menjadi lebih mudah dikembangkan,dan dikelola.
